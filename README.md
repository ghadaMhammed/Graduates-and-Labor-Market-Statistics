# احصائيات الخريجين وسوق العمل!
تبرز هذي اللوحة نسبة الملتحقين بسوق العمل لخريجين الجامعة السعودية الالكترونية لعام 2025. البيانات منشورة في <a href="https://open.data.gov.sa/ar/datasets/view/f68cdee0-0181-46b0-b3ae-f56edd435805"> منصة البيانات المفتوحة <a/>. بالنسبة لي كان رسالة اللوحة هل دخول الخريجين لسوق العمل سريع؟ وماهي نسب الذين التحقوا بسوق العمل وماذا كانت تخصصاتهم؟


#### أهم الاستنتاجات اللي تظهرها اللوحة هي:
- نسبة الخريجين الذين مر عليهم أكثر من 12 شهر بدون وظيفة 49.65%!
- يعتبر نسبة خريجين التسويق الرقمي من أكثر من التحق بوظيفة 87.50% وأقلهم نسبة هم خريجين تخصص المعلوماتية الصحية.
- واخيراً نسبة المتوظفين قبل تخرجهم يشكلون النسبة الاضخم من إجمالي الملتحقين بسوق العمل بواقع 91.50%!
